# Curated visual assets

Downloaded from the official Kenney pack pages on 2026-11-14. Both current pack pages and
the included license files say CC0. Three unmodified PNGs total; dimensions and stable IDs
are in src/visuals/assets.ts. The build embeds only these approved local files as data URLs.
The blue flag marks the projectile target; its pixels do not determine the hit geometry.
The star and checkmark are available decorations, never evidence of independent mastery.

Physics Assets 1.0: https://kenney.nl/assets/physics-assets
UI Pack 2.0: https://kenney.nl/assets/ui-pack
License: https://creativecommons.org/publicdomain/zero/1.0/

PhET activities are links only. No simulation code or media is bundled or embedded, and
no simulation state is assumed observable. Official licensing page checked 2026-11-14:
https://phet.colorado.edu/en/licensing (client-rendered terms were not available as static
text, so this implementation does not rely on an embedding or redistribution license).

Commons search and generated art are unnecessary for this small approved pack workflow.
